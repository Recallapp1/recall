## Switches

Each switch is a Vercel environment variable (Production). Add it, then redeploy; remove it and redeploy to turn it off. Every switch was built so that **unset means the behaviour before the switch**, and a test proves that.

**On in production (2026-10-19, 17):** `AUDIT_STRICT`, `CALL_REVIEW`, `PANEL_GO_LIVE_CHECK`, `PANEL_LIMITS_VIEW`, `TEST_CALL_FLAG`, `TWO_FACTOR_RESET_EMAILS`, `PANEL_TWO_FACTOR=optional`, `POST_CALL_FLAGS`, `VOICE_TOOL_IDEMPOTENCY`, `VOICE_EMERGENCY_FIRST`, `VOICE_EMERGENCY_END_CALL`, `UNBACKED_CLAIM_EMAIL`, `VOICE_TOOL_ERROR_HINT`, `VOICE_VERIFIED_SERVICE`, `VOICE_VERIFY_HINT` (exactly `true`, confirmed by you on 2026-10-19; Vercel does not show the value), `VOICE_BOOKING_RULES`, `VOICE_NO_NAME_ADDRESS`. Also set: `HEALTH_JOBS_TOKEN`, `SENTRY_DSN` (Sentry project in the EU region, confirmed 2026-10-19). Every other switch in the table is unset (off).

> **Type values exactly.** On/off switches accept only `true` or `false` (lower case); unset is the same as off. Anything else (`TRUE`, `1`, `yes`, a stray space) fails the settings check on the first request, and **every request that reads settings then fails**: panel, voice webhooks and cron. The same applies to `PANEL_SESSION_HOURS` (a whole number 1–168), `VOICE_PROMPT_VARIANT` (`full` or `compact`) and `PANEL_TWO_FACTOR` (`off`, `optional`, `required-admins` or `required-all`). After any change, check `/api/health` and open the panel once.

`RETELL_LLM_MODEL` (`claude-4.5-haiku`), `RETELL_VOICE_MODEL` (`eleven_flash_v2_5`) and `RETELL_LLM_HIGH_PRIORITY` (`false`) are already set in Production and should stay; removing `RETELL_VOICE_MODEL` is not a no-op.
